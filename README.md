# Electric Vehicle (EV) Performance & Efficiency Simulation

This project models and simulates key vehicle and electrical dynamics for an Electric Vehicle (EV), focusing on battery State of Charge (SOC), target deceleration, and regenerative braking efficiency using MATLAB.

---

## Features

* **Vehicle & Electrical Specifications:** Includes total mass, wheel radius, nominal voltage, battery capacity, and initial SOC.
* **Preallocated Data Arrays:** Optimized array handling for real-time speed, efficiency, torque demand, and energy regeneration calculation.
* **Initial Conditions Setup:** Automatic conversions (e.g., speed from km/h to m/s) and initial status tracking.
